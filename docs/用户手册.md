## 1. 系统简介

松果集市 是一个集新品与二手商品交易、AI 智能议价、社区互动于一体的综合电商平台。平台支持 H5 网页与微信小程序双端访问，主要功能包括：

- 商品浏览与搜索
- 购物车与订单管理
- 买家/卖家双角色切换
- AI 智能议价助手
- 即时聊天与客服转接
- 社区话题互动
- 信用评价体系

## 2. 快速开始

### 2.1 注册与登录

**注册账号：**

1. 进入"我的"页面，点击"登录/注册"
2. 选择"注册"标签页
3. 填写用户名、密码、手机号
4. 点击"注册"按钮完成注册

**登录账号：**

1. 在登录页输入用户名和密码
2. 点击"登录"按钮
3. 演示账号：用户名 `demo`，密码 `demo123`

**切换角色：**

登录后在"我的"页面可切换买家/卖家/管理员视图：

- **买家视图**：浏览商品、管理订单、查看收藏
- **卖家视图**：管理店铺、发布商品、处理订单
- **管理员视图**：审核商品、管理用户

## 3. 功能详解

### 3.1 首页浏览

首页展示推荐商品、新品上架和二手精选，支持按"新品"/"二手"/"全部"分类查看。

- 顶部搜索栏可快速搜索商品
- 商品卡片展示价格、成色、店铺等信息
- 点击商品卡片进入商品详情页

### 3.2 商品搜索与筛选

在搜索页可按关键词搜索商品，支持以下筛选：

- **场景**：新品 / 二手 / 全部
- **分类**：数码影音 / 服饰箱包 / 图书教育 等
- **价格区间**：自定义最低价 ~ 最高价
- **排序**：综合 / 价格从低到高 / 价格从高到低 / 最新发布

### 3.3 商品详情

商品详情页展示：

- 商品图片与基本信息（标题、价格、成色）
- 商品参数（品牌、型号等）
- 商品故事（二手物品流转故事）
- 信用标签（卖家信用分、平台担保标识）
- 商品评价
- AI 交易提示

操作入口：
- **立即购买**：直接下单购买
- **加入购物车**：先加入购物车
- **联系卖家**：进入聊天界面
- **收藏/分享**：收藏商品或分享给好友

### 3.4 购物车

购物车功能：

- 查看已添加的商品列表
- 调整商品数量
- 删除购物车商品
- 选中商品后点击"去结算"进入订单确认

### 3.5 订单管理

**下单流程：**

1. 从商品详情页或购物车进入订单确认页
2. 填写或确认收货地址
3. 选择支付方式
4. 提交订单

**订单状态：**

| 状态 | 说明 |
|-----|------|
| 待付款 | 订单已创建，等待支付 |
| 待发货 | 支付完成，等待卖家发货 |
| 待收货 | 已发货，等待买家确认收货 |
| 待评价 | 已收货，等待买家评价 |
| 已完成 | 已评价，交易完成 |
| 已取消 | 订单已取消 |

**订单操作：**

- 查看物流信息
- 确认收货
- 发表评价
- 申请售后

### 3.6 聊天与 AI 议价助手

**进入聊天：**

在商品详情页点击"联系卖家"或在消息列表中选择会话进入聊天界面。

**AI 智能回复：**

- 当买家发送消息后，AI 助手自动以卖家身份回复
- AI 回复内容基于商品信息和历史对话生成
- 注意：AI 回复仅供参考，不构成交易承诺

**转接人工客服：**

AI 回复后会弹出提示框询问"是否需要转接人工客服继续沟通？"
- 点击"转人工客服"：切换到真人客服模式
- 点击"继续沟通"：继续与 AI 助手交流

**手动触发 AI 议价：**

当对方的消息中包含价格、优惠等关键词时，底部会显示"启用 AI 议价"按钮，点击后 AI 会生成议价建议。

### 3.7 发布商品

卖家可通过发布功能上架商品：

**发布新品：**

1. 进入"发布"页面
2. 选择"新品"标签
3. 填写商品标题、价格、分类、描述等信息
4. 上传商品图片
5. 点击"发布"提交审核

**发布二手：**

1. 进入"发布"页面
2. 选择"二手"标签
3. 填写商品信息外，还需填写：
   - 成色描述（如 9 成新）
   - 使用时长
   - 流转故事（可选）
4. 点击"发布"提交审核

**审核流程：**

发布后商品进入待审核状态，管理员审核通过后正式上架。

### 3.8 社区话题

社区模块允许用户浏览和参与商品相关话题讨论：

- 浏览热门话题
- 查看话题详情与评论
- 参与话题讨论（需登录）

### 3.9 个人中心

**买家视角：**

- 个人信息：用户名、手机号、信用分
- 收藏夹：收藏的商品
- 浏览历史：最近浏览的商品
- 关注店铺：关注的店铺列表
- 实名认证：提交实名认证信息

**卖家视角：**

- 店铺仪表盘
- 待发货订单
- 销售额统计
- 商品管理（已发布商品列表）

**管理员视角：**

- 用户管理
- 商品审核
- 信用调整

### 3.10 地址管理

在地址管理页面可：

- 新增收货地址
- 编辑已有地址
- 设为默认地址
- 删除地址

## 4. 常见问题

**Q：如何切换买家/卖家模式？**  
A：在"我的"页面点击角色切换按钮，可在买家、卖家、管理员间切换。

**Q：AI 议价可靠吗？**  
A：AI 议价助手基于商品标价和底价给出建议，仅供参考。实际交易价格需要买卖双方协商确认。

**Q：如何联系人工客服？**  
A：在聊天界面中，AI 回复后会弹出转接提示，点击"转人工客服"即可。也可以联系平台管理员。

**Q：发布商品后多久能上架？**  
A：商品发布后需管理员审核通过才能上架，审核时间请咨询平台管理员。

**Q：如何查看物流信息？**  
A：在订单列表点击对应订单，进入订单详情后查看物流信息。

**Q：忘记密码怎么办？**  
A：当前版本暂不支持密码找回功能，请联系管理员重置密码。
