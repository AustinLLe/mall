## 1. 测试概述

### 1.1 测试目的

本测试文档旨在验证松果集市交易平台的各项功能是否满足设计要求，确保系统在上线前达到预期的质量和稳定性。

### 1.2 测试范围

| 模块 | 测试内容 |
|------|---------|
| 认证模块 | 注册、登录、Token 鉴权 |
| 商品模块 | 商品浏览、搜索、详情、发布 |
| 购物车模块 | 添加、删除、数量调整 |
| 订单模块 | 下单、物流、评价 |
| 聊天模块 | 消息发送、AI 回复、转人工客服 |
| AI 议价 | AI 建议生成、自动回复 |
| 用户中心 | 买家/卖家/管理员中心 |
| 管理审核 | 商品审核流程 |
| 社区话题 | 话题浏览与评论 |

### 1.3 测试策略

- **功能测试**：手工执行，覆盖全部业务路径
- **接口测试**：通过 API 请求验证后端接口的正确性
- **兼容性测试**：在不同浏览器和设备上验证前端展示
