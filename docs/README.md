# 松果集市项目说明

本项目是一个“新品购物 + 二手交易”的综合交易平台，前端使用 uni-app / Vue 3，后端使用 Spring Boot，目标运行端包括 H5 网页和微信小程序。

## 当前功能范围

- 用户体系：注册、登录、个人中心、信用分展示、手机号脱敏。
- 商品浏览：首页推荐、搜索筛选、新品/二手切换、分类筛选。
- 商品详情：价格、服务保障、卖家信息、参数、评价、二手物品时间线、AI 议价入口。
- 社区发现：话题清单、二手故事、热门店铺。
- 交易流程：购物车、确认订单、模拟支付、订单列表、物流跟踪、评价。
- 发布与审核：商品发布、AI 发布建议、我的发布、管理员审核模拟。
- 后端接口：认证接口、商品/店铺/话题/订单/发布/审核/AI 助手的内存模拟接口。

## 目录说明

- `shopping_front/`：uni-app 前端项目。
- `shopping_back/shopping_back/`：Spring Boot 后端项目。
- `docs/`：项目说明、接口文档、运行部署和协作规范。

- `docs/api.md`：后端接口说明。

## 协作要求

从现在开始，任何代码修改完成后，都必须同步检查并更新相关文档：

- 修改页面、路由、组件：更新 `frontend-structure.md`，必要时更新 `wechat-devtools.md`。
- 修改接口、DTO、返回字段：更新 `api.md`。
- 修改运行、编译、部署方式：更新 `deploy.md` 或 `wechat-devtools.md`。
- 修改协作流程或开发约定：更新 `change-policy.md`。

提交或交付前，需要在回复中说明“代码改了什么，文档同步改了什么”。
