# 需求说明（骨架）

本文档用于沉淀「购物 + 二手」综合平台的产品范围，随迭代补充。

## 一期目标（当前）

- 多端统一技术栈：uni-app（Vue3）+ Spring Boot + MySQL
- 先完成 **H5 网页** 主流程骨架与可部署产物
- 后端提供统一 JSON 结构与基础联通接口
- **账号注册 / 登录 / 当前用户**（内存存储，便于先跑通前后端；后续换 MySQL + 正式鉴权）
- 前端信息架构：**首页 · 逛逛 · 购物车 · 我的**，与《交易平台功能思考》中的用户、商品、订单、会话等模块对齐占位

## 功能模块（占位）

- 商品浏览与搜索
- 下单与支付（后续）
- 二手发布与交易（后续）
- 信用评价（后续）
- 个人店铺（后续）
- 物流跟踪（后续）

## 非功能要求（占位）

- 安全：HTTPS、鉴权、敏感信息不入库明文
- 可用性：核心接口监控与日志
